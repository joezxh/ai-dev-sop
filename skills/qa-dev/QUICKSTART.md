# /qa-dev Skill 快速使用指南

## 一句话说明

**`/qa-dev`** = `/qa` 全部严格测试能力 + 测试开发一体化 + 批量无人值守

---

## 核心能力

### 继承 /qa 全部严格测试功能

| 能力 | 说明 |
|------|------|
| 三级测试级别 | Quick/Standard/Exhaustive |
| 健康分数评分 | 0-100分 |
| Diff-aware模式 | 智能聚焦变更 |
| 响应时间监控 | 性能检测 |
| 原子提交修复 | 规范修复记录 |
| 自动回归测试 | 预防回归问题 |

### /qa-dev 独有功能

| 能力 | 说明 |
|------|------|
| 批量无人值守 | 一键执行所有模块 |
| 测试+开发一体 | 发现问题自动修复 |
| 场景文件驱动 | 根据文档定制测试 |

---

## 快速开始

### 批量执行 (推荐)

```bash
# 完整测试 + 自动修复 + 开发 (Standard级别)
/qa-dev --batch --file ai-scene.md

# 快速测试 (关键路径)
/qa-dev --batch --tier quick --file ai-scene.md

# 穷尽测试 (包含低优先级问题)
/qa-dev --batch --tier exhaustive --file ai-scene.md

# 仅测试 + 生成报告
/qa-dev --batch --test-only --file ai-scene.md
```

### 单模块执行

```bash
/qa-dev --file ai-scene.md --module AI-01
/qa-dev --file ai-scene.md --module AI-01 --tier exhaustive
/qa-dev --test-only --file ai-scene.md --module AI-01
```

---

## 三级测试级别

| 级别 | 命令 | 修复范围 |
|------|------|---------|
| 快速 | `--tier quick` | Critical + High |
| 标准 | `--tier standard` | + Medium |
| 穷尽 | `--tier exhaustive` | + Low + 样式 |

---

## 健康分数评分

| 分数范围 | 等级 | 说明 |
|---------|------|------|
| 90-100 | 优秀 | 应用质量良好 |
| 70-89 | 良好 | 有少量问题 |
| 50-69 | 一般 | 需要修复 |
| 30-49 | 较差 | 存在严重问题 |
| 0-29 | 危险 | 核心功能不可用 |
